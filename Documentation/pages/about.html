About Omnipet

The project, how it is built, and where to find the community.

Project overview

Omnipet started as a fan project to play the classic virtual pets on one device. Each device is recreated as a module, following its manual and, where possible, measurements of the real hardware, so the Digimon of many devices can be raised side by side.

This is a fan project with no connection to the manufacturers of the original devices.

Key features

ModulesEach device is data: Digimon, evolution routes, care rules, battles, items and backgrounds.
EvolutionBranching routes that read care, training, battles and each device's own values.
BattlesAdventure areas, Versus, Jogress, DCom battles with real devices, WiFi and online battles, Arena seasons.
Module EditorA Windows program that creates, checks, documents and publishes modules.

Technology

Omnipet is written in Python with pygame. It runs on Windows, Linux, the Raspberry Pi (GamePi), Batocera and Android. Omninet, the online service for accounts, the Shop and the Arena, is a separate server. The Module Editor is a C# Windows Forms program.

Community

Questions, bug reports and module sharing happen on Discord. The source and the releases are on GitHub.
