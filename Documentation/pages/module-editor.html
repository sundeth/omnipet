Getting started

A module is a folder inside the game's modules folder: JSON files that describe a device (its Digimon, evolutions, care rules, battles and items) plus its sprites. The Module Editor edits those files. It runs on Windows with the .NET Framework 4.8.

Module selector

The editor opens on the module selector, which lists the folders of the modules folder. On the first run it lists the modules folder next to the editor's Module Editor folder; the folder chosen with Find... is remembered.

ControlWhat it does
Path boxThe modules folder being listed.
Find...Picks the modules folder. Choose the folder that holds the modules, not a module itself.
ListOne line per module folder. Double-click opens the module.
AddAsks for a folder name ("Module folder name:"), creates the folder with a module.json from the editor's template, its Name set to the folder name, and opens it. An existing folder is refused ("Module already exists.").
RemoveDeletes the selected folder and everything in it, after a confirmation. It cannot be undone.
EditOpens the selected module.
The editor writes straight into the module folder, and several buttons write at once (see Saving). Keep a copy of a module before large changes.

Making a module

  1. In the selector, Add a module and name its folder.
  2. On the Module tab, set the name, the three images and the device's rules (care, battle, death).
  3. On the Pet tab, Add each Digimon, starting with the egg (stage 0), and give each its sprites.
  4. Open Edit Evolutions and draw the evolution routes; set each route's requirements and order.
  5. Add the adventure enemies on the Battle tab, and the unlocks and backgrounds on the Module tab.
  6. Save (Ctrl+S), then run Tools > Module Report and fix what it lists.
  7. Documentation > Create Documentation writes the module's guide.

Saving

Save (or Ctrl+S) writes every tab's file and shows "Module saved!". Close never asks: anything not saved is lost. On tabs with a list and a form, the form's own Save button puts the edits into the entry; the main Save then writes the file. Some actions write their file at once.

A file the editor cannot read opens as an empty list, and the next Save writes it back empty. If a tab opens empty when it should not, close without saving and fix the file first.
Ctrl+C and Ctrl+V duplicate the selected entry on the Module (Unlocks, Backgrounds), Pet, Battle, Item, Quests/Events (Quests, Events) and Passwords tabs, while the cursor is not in a text field. The copy stays inside the editor. A pasted pet or enemy keeps the original's name: rename it, since evolutions and enemies find a Digimon by name.

Module tab▼

The Module tab has three sub-tabs: Main (the module's settings), Unlocks and Backgrounds. Main shows the three images and the header fields above four inner tabs: Main, Battle & Training, Care & Death and Misc. Every label and field has a tooltip.

Export Sprites and Generate Pet Index

Tools > Export Sprites (Ctrl+E) asks for a folder and writes <module name>/<monsters|monsters_dot|monsters_hidef>/<Name>_dmc.zip for every pet and enemy, taking the first set found (module or shared assets), then lists the names it could not find.

Tools > Generate Pet Index renumbers Index for every pet in list order, from 0 within each version (eggs -1), and writes monster.json at once.

Index is the Digimon's number on the device. Generate Pet Index replaces device numbers that are not consecutive; do not use it on a module whose numbers come from the device.

Omninet▼

Account

Omninet > Account opens the account window. Logged out it offers Create New Account (nickname, e-mail, password, then a code sent by e-mail) and Login with Existing Account (e-mail and password, then a code). Logged in it shows the nickname and e-mail with Link Game Device (a 4-character code for the game's Link Device button, valid 5 minutes), Logout and Close. The session is kept in %APPDATA%\OmnipetModuleEditor and checked each time a module opens.

Manage Module

Omninet > Manage Module (logged in) saves every tab and checks the module's name and Version with Omninet. A free name offers Publish New; a module you own or contribute to offers Update Module, Unpublish (owner only) and Contributors; a name owned by someone else cannot be published.

Publishing needsUploaded
logo.png and Flag.png; BattleIcon.png and at least one adventure enemy with Adventure Mode; at least one pet.The whole module folder as a ZIP, with the name, version, description and category read from its module.json.

Module Library

Omninet > Module Library lists every published module (no login needed) with Author, Category, the installed and Omninet versions and your Ownership. Download, Update or Reinstall installs a module into the modules folder; the module open in the editor cannot be replaced.

Update and Reinstall delete the installed module's folder before extracting the download. Copy any local changes first.
