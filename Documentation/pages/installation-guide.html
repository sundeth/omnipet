Install

For Windows 10 and 11. Python is built into Omnipet.exe: there is nothing else to install.

  1. Download Omnipet_Windows_Ver_1.0.1.zip.
  2. Extract all files to a folder of your own, such as C:\Games\Omnipet.
  3. Double-click Omnipet.exe.
Unsigned program. Omnipet.exe is not signed, so Windows may show "Windows protected your PC". Click More info, then Run anyway.

Nuitka build

Omnipet_Nuitka_Windows_Ver_1.0.1.zip is the same game compiled with Nuitka. It is experimental: use it if the standard build runs slowly. Start it with omnipet.exe and keep the .pyd and .dll files beside it.

The game's Python source with launch scripts, for Windows and Linux. It needs Python 3.10 or newer with pygame and requests: see Python packages.

Windows

  1. Install Python 3.10 or newer from python.org. Tick the option that adds Python to PATH: launch.bat runs python.
  2. Open Command Prompt and install the packages: 
    python -m pip install pygame requests psutil
  3. Extract Omnipet_Python_Desktop_Ver_1.0.1.zip to a folder of your own.
  4. Double-click launch.bat. It stops with a message when Python or pygame is missing.

Linux

  1. Install Python 3.10 or newer and the packages (table below). Check the version with python3 --version: Raspberry Pi OS Bullseye's Python 3.9 is too old.
  2. Extract the zip: 
    unzip Omnipet_Python_Desktop_Ver_1.0.1.zip -d ~/Omnipet
  3. Make the launcher executable and start the game: 
    cd ~/Omnipet
chmod +x launch.sh
./launch.sh

launch.sh uses the first of python3.14 down to python3.10, python3 and python that is 3.10 or newer and has pygame. It picks the display driver: Wayland, X11, or KMS/DRM on a console with no desktop.

For the GamePi handheld (Raspberry Pi Zero 2W) and other Raspberry Pi boards. setup.sh also installs on Debian, Ubuntu, Fedora and Arch.

From the zip

  1. Copy Omnipet_GamePi_Ver_1.0.1.zip to the Pi and extract it into the game folder. The GamePi uses ~/Games/Omnipet: 
    mkdir -p ~/Games/Omnipet
unzip -o Omnipet_GamePi_Ver_1.0.1.zip -d ~/Games/Omnipet
  2. Run the setup script once (table below): 
    cd ~/Games/Omnipet
bash setup.sh
  3. Install requests, which setup.sh does not install, for the Python it named in "Installing Python packages for ...". For python3.10, or for a system python3 of 3.10 or newer: 
    python3.10 -m pip install --user requests
sudo apt install python3-requests
  4. Start the game: 
    ./launch.sh
    On a console with no desktop the game uses KMS/DRM and runs fullscreen.

SD card image

Omnipet_GamePi_Ver_<version> (Image).zip is a ready SD card with the system, Python 3.10 (/usr/local/bin/python3.10) and the game installed. Use it for new setups or a full reinstall.

  1. Unzip it to get the .img file.
  2. Write it with Raspberry Pi Imager (Choose OS, Use custom). In the OS customisation settings, set your WiFi network and enable SSH: without WiFi you cannot reach the Pi to update it.
  3. Insert the card and power on. The system grows to fill the card on the first boot, and Omnipet starts as a service.

Nuitka build

Omnipet_GamePi_Nuitka_ARM_Ver_1.0.1.zip is the game compiled with Nuitka. It is experimental and has no launch script. Extract it, then from its folder:

chmod +x omnipet

For Batocera's Pygame system. omnipet.pygame is the launcher EmulationStation lists; it starts the game fullscreen from its own folder. input_test/input_test.pygame shows what each key, joystick button, axis and GPIO pin sends.

  1. Extract Omnipet_Batocera_Ver_1.0.1.zip into a folder named omnipet.
  2. Copy that folder to /userdata/roms/pygame/, over the network share (\\batocera on Windows, smb://batocera on Linux; folder roms/pygame) or over SSH (ssh root@batocera, password linux).
  3. Make the launcher executable over SSH: 
    chmod +x /userdata/roms/pygame/omnipet/omnipet.pygame
  4. Update the game lists in EmulationStation, or restart Batocera. Omnipet appears under Pygame.

On Batocera the game always runs fullscreen and tries the KMS/DRM display driver first. The save is in /userdata/roms/pygame/omnipet/save. The game needs Python 3.10 or newer with pygame and requests.

Omnipet_Android_Ver_1.0.1.apk is for Android 5.0 or newer on 64-bit ARM (arm64-v8a). The app is Omnipet VPet Simulator; it runs fullscreen in landscape.

  1. Download the APK on the phone or tablet.
  2. Open it and install. Android asks once to allow installs from the app that opened it (the browser or the file manager).
  3. Open Omnipet VPet Simulator.
  4. Allow notifications if Android asks: care calls and events arrive as notifications while the app is closed.

When you come back, the time the app was closed is played through as if it had stayed open. The save and the downloaded modules are kept in the app's own storage, and uninstalling the app deletes them. To update, install the new APK over the installed app.

First start

  1. Setup: map your buttons (keyboard, gamepad or GPIO), then the graphics test. On a keyboard or gamepad START or B skips; touch screens show a Skip button.
  2. Choose Progress Mode (shown as Progression Mode) or Free Mode. Progress Mode signs in to Omninet and opens the Arena and the whole shop. Free Mode unlocks every module and feature at once, without the Arena. See Online Play.
  3. The tutorial follows. With no module installed it covers the module shop, and the egg screen opens the shop instead.

Offline with no module installed, the game shows NO MODULE DETECTED: connect to the internet or add a module by hand.

Settings

There are no configuration files to edit: display, sound, gameplay and button settings are in the game's Settings menu and are saved with your game (buttons: Settings > Input > Remap Input). Each platform starts with its own defaults. See the Manual.

Modules

From the shop

Connect > Shop > Modules lists the published modules.

ModeDownloads
Free ModeEvery module is free. No Omninet account is needed.
Progress ModeSign in to Omninet. A module is bought once with coins; the modules you own are downloaded to every device linked to the account.

A module's page shows Download, Update when a newer version is published, or Updated. An update replaces the installed module only once the download is complete.

By hand

Every build except Android also loads modules copied into the modules folder: one folder per module, with module.json directly inside, as in modules/DMC/module.json. Restart the game to load it. A module that fails to load shows "Error loading module" and its name on the main screen.

A module's documentation, when it has one, is at modules/<NAME>/documentation/index.html.

Each save folder holds save_data_1.dat to save_data_10.dat (the game writes the next one each time and loads the newest), freezer.pkl (the Freezer) and digidex.json (the Digidex). The game saves every minute and when it closes.

To back up the game, or move it to another computer or a GamePi, copy the whole save folder while the game is closed.

Updating

Windows, Python Desktop, GamePi and Batocera

  1. Close the game.
  2. Copy the save folder somewhere safe, and modules if you added modules by hand.
  3. Extract the new release into the game folder, replacing the old files. Its modules and save folders are empty, so your save and modules stay. On a GamePi, over SSH: 
    unzip -o Omnipet_GamePi_Ver_1.0.1.zip -d ~/Games/Omnipet
  4. Start the game, then open Connect > Shop > Modules and update the modules that show Update.

Android

Install the new APK over the installed app. Do not uninstall first: that deletes the save.

From 1.0.0 Beta 3

  • Saves carry over.
  • The original Digital Monster and Pendulum modules are now DMOG and PENOG. Your Digimon from them move to the new names when the save loads: install DMOG and PENOG from the shop to keep playing them.
  • A sick Digimon keeps its ailment as the kind it was; its old count becomes its injury count.
  • The config folder of older releases is no longer used and can be deleted.

Start options

OptionEffect
--fullscreen or -fStarts fullscreen, scaled to the screen. Works with Omnipet.exe, omnipet.exe, main.py, launch.sh and launch.bat.
OMNIPET_FULLSCREENThe same, as an environment variable: 1, true or yes.
SDL_VIDEODRIVERChooses the display driver. Without it the game tries windows on Windows; x11, wayland, kmsdrm, fbcon on Linux; kmsdrm first on Batocera. launch.sh sets it itself. kmsdrm always runs fullscreen.
 
Omnipet.exe --fullscreen
./launch.sh -f
python3 main.py --fullscreen
OMNIPET_FULLSCREEN=1 ./launch.sh

Windows starts in a window. Linux, the Raspberry Pi, Batocera and Android start fullscreen.

Start the game from its own folder. The game reads assets, modules and save from the folder it starts in. launch.sh, omnipet.pygame and the Nuitka builds change to their folder themselves. Omnipet.exe and launch.bat do when double-clicked; a shortcut to them needs the game folder as its Start in folder.

Problems starting the game are covered in Troubleshooting.
