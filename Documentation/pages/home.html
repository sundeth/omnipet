Omnipet

A modular virtual pet simulator for Windows, Linux, Raspberry Pi handhelds, Batocera and Android.

About the project

Omnipet raises Digimon the way the virtual pet devices do. Each device is a module: its Digimon, evolution routes, care rules, battles, items and backgrounds are data that the game reads, so the same game plays the Digital Monster, the Pendulum, the Digivice iC, the Vital Bracelet and more, side by side in one party.

Omnipet can battle real devices through a DCom adapter, other Omnipets on the same network, and other players online through Omninet, the Arena and Discord. The Module Editor creates and edits modules.

This is a fan project with no connection to the manufacturers of the original devices.
