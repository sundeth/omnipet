Evolution and care

My Digimon is not evolving

When its evolution time comes, the game reads the form's evolution routes in the order the module lists them. The first route whose requirements are all met is taken. Each requirement is a range: one value outside its range rules the route out, and the next route is tried.

  1. Wait for the evolution time. Each form has its own. Devices that show it have an Evolution Timer box on the Status screen.
  2. Answer every care need. An awake Digimon does not evolve while Hunger or Strength is empty, while it is sick or injured, or while it is awake after bedtime. The evolution time keeps counting. Once the need is answered, it evolves at the next minute.
  3. Compare its counters with the routes. Open the module in the Module Guide, page Evolution Charts. Read the current form's routes from the top. The Status screen shows the counters this device shows.
  4. Check for a locked form. A secret form stays locked until its unlock is earned. Its route is skipped. Settings › Secrets lists each module's unlocks.
  5. Check for a failed evolution (below).

Most counters start at zero in each new form. On a few devices, the Digimon Mini and the Digivice iC among them, battles and wins carry over.

Sleep

On the original Digital Monster (DMOG), the Digital Monster Ver.20th (DM20) and the Vital Bracelet (VB), time asleep does not count, and a sleeping Digimon does not evolve. On the other modules the evolution time runs during sleep, and a sleeping Digimon can evolve.

Failed evolutions

One try. If any route of the current form reads the win ratio, the Digimon gets one try when its evolution time comes. If it meets no route, or loses the chance roll, the evolution fails. The timer never evolves that form again. Nothing on screen marks it: the time passes and the form stays.

The same applies to every form from Perfect on the Digital Monster X, and from Adult on the Pendulum Z, win ratio or not.

A failed form can still change through items, jogress, armor evolution and Level Reverse. On the Pendulum Color, Pendulum Color Godzilla, Pendulum Ver.20th, Digital Monster X and Pendulum Z, its hearts then deplete twice as fast and it poops twice as often.

On these forms, meet a route's requirements before the evolution time comes.

My Digimon sleeps at the wrong time

Each form sleeps and wakes at its device's times. Settings › Gameplay › Wake and Sleep replace them for every Digimon. Set both: with either one Off, the device times apply. A form with no sleep schedule is not affected.

Modules and modes

The game has no modules

The downloads come with an empty modules folder. Modules come from the Shop, or are copied in by hand.

  1. Connect › Shop › Modules downloads a module. It needs an internet connection.
  2. Or copy a module folder into modules. The folder must hold module.json directly: modules/DMC/module.json. A zip file, or a folder inside a folder, is not read.
  3. Start the game again.

With no module and no connection, the game starts on NO MODULE DETECTED: "Connect to the internet or install a module manually".

A module is missing from the egg screen

  • Progress Mode lists only modules you own. A module copied in by hand but not bought is not listed.
  • Modules are grouped: Classic, Modern, Conversions, Custom. A group with no module is dimmed.
  • A module with no egg is not listed.
  • A device is offered only when one of its eggs is available now. Secret eggs appear once their unlock is earned (Settings › Secrets). Eggs held back for a later version are not offered.
  • A module that fails to load is skipped. The main screen shows Error loading module <folder>.

A module is missing from the Module Guide

The Module Guide is rebuilt each time the game starts, from the installed modules that carry documentation/index.html. Start the game once after installing. A module without documentation is not listed.

My Digimon are gone after changing mode or account

Free Mode and each Omninet account have their own save folder. Nothing is deleted. Switch back to the mode and account you played on.

DCom

The DCom adapter is not recognized

Connect › Local Battle looks for an adapter every 3 seconds while it is open. The DCom button lights when the system lists a USB serial port. Local Battle itself needs a Digimon in the party.

  1. Plug the adapter in with the menu open. Wait a few seconds.
  2. Check that the system sees it: a COM port in Windows Device Manager, a /dev/tty… device on Linux. If it does not appear, install the driver for the adapter's USB-serial chip.
  3. Running from source (Python Desktop, GamePi): install pyserial with pip install pyserial. Without it the console prints pyserial not installed. DCom functionality disabled.
  4. Several USB serial devices plugged in: the game lists them all. Pick the adapter. It names the USB id 1A86:7523 (CH340) "DCom" and lists any other port by its own name.
DCom is not available on Android: the Android build has no serial support.

The adapter is found but the battle does not start

After the device line and the charge, the game opens a 60-second window. Start the battle on the device, or press START. After 30 seconds of silence the game swaps roles once and asks: "Start battle on the device, then connect it."

What does "(paused)" mean?

The adapter printed (paused) instead of running the command. The classic dmcomm Arduino firmware stops any command whose signal letter it does not know; it knows V, X, Y and C. The game treats this as a refusal and ends the attempt at once. A Pico adapter reports CommandError instead.

WiFi and Discord

The WiFi button is dimmed

The WiFi button needs a local network address. It does not need internet: a phone hotspot works. Connect the device to a network and open Connect › Local Battle again.

The WiFi battle host is not found

The joining game asks the local network for hosts for 3 seconds. Hosts answer on UDP port 47555. The battle then runs over a TCP port the host picks at random.

  1. Put both games on the same local network. The search is a broadcast on that network.
  2. Host first. The host shows "Hosting WiFi battle", a Code and its IP. Then Join Battle on the other game, or Search again.
  3. Allow Omnipet through the firewall on both computers (Omnipet.exe, or Python when running from source). The host receives the search on UDP 47555 and the connection on its TCP port.
  4. Two games on one computer also work: the search includes the computer itself.

Cannot host on this networkThe game could not open a network port. Check the network connection.

The WiFiCom button is dimmed

WiFi-Com battles are switched off in 1.0.

Discord linking says offline or invalid

Link in Connect › Config › Discord › LINK. Send !link in Discord to get a 4-character code, then enter it. Discord battles work in both modes.

Arena

The Arena button is dimmed

  • Free Mode has no Arena. Switch to Progress Mode.
  • The party has no Digimon.

The Arena shows no season

No active season and SEASON NOT STARTED mean no season is running, or the server could not be reached: the hub shows the same in both cases. Check the connection and open the Arena again. Seasons last a week by default. Season over: results in a moment... shows while a finished season's results are on the way.

A Digimon is locked in the Freezer

A team's Digimon go to the Freezer when the team is registered, locked until the season ends. The Freezer shows Arena <time> in place of Add. The lock ends at the season's end time, even offline. Open the Arena after the season: each Digimon gets its team's battle record.

Backups and restoring an older save

The game saves every minute, when you quit, and when Android sends it to the background. At start it loads the newest file. If that file cannot be read, it tries the one before.

  1. Close the game.
  2. Copy the mode folder somewhere safe.
  3. Sort the save_data_N.dat files by date modified. Move out every file newer than the one you want.
  4. Start the game. It loads the newest file left.
The Freezer and the Digidex are single files. Restoring an older save_data file does not restore them.

Moving a save to another computer

  1. Close the game on both computers.
  2. Copy the mode folder (Default, or your account's folder) into the new game's save folder.
  3. Start the new game. Free Mode: choose Free Mode. Progress Mode: log in with the same account; the game opens your account's folder.
Settings (display, sound, buttons) are stored in the save. After moving between platforms, check Settings › Display and Settings › Input › Remap Input.

Android

Does my Digimon live while the app is closed?

Yes. There is no background service. When you come back, every minute you were away is played through as if the app had stayed open: care calls, poop, sickness, evolution, death, sleep and midnight. There is no limit on the time away. A reboot, a time-zone change and a clock set back or forward are handled.

I get no notifications

Reminders are planned when you leave the app, up to seven days ahead, and Android delivers them. They are cancelled while the game is open.

  1. Allow notifications. Android 13 and later ask when the game first starts.
  2. Check Settings › System › Notifications in the game: Enabled or Disabled.
  3. Settings › System › Notification Settings opens Android's page for Omnipet. Three channels can be switched separately: Pet care (calls, sickness, dying), Pet cleanup (poop) and Random events.
  4. Open the game at least once a week. The plan covers seven days from your last visit.
No battery exemption is needed. Android may deliver a reminder late; when several of one kind are due together, one notification gives the count, such as "3 pets need attention".
Tap a random event's notification within five minutes to open the event.

GamePi and Batocera

The game does not start on a Raspberry Pi

Start it with launch.sh. It picks the display driver: Wayland or X11 on a desktop, KMS/DRM on the console with no desktop. It looks for Python 3.10 or newer with pygame: a Python-3* folder in the game folder, then python3.14 down to python3.10, then python3. The GamePi image has /usr/local/bin/python3.10. Raspberry Pi OS Bullseye's python3 is 3.9, too old.

MessageWhat to do
Error: no Python 3.10 or newer with pygame foundInstall Python 3.10 or newer and pygame, or use the GamePi image. setup.sh installs pygame for the newest Python 3.10+ it finds.
No compatible SDL video driver found!No display driver started. Start the game with launch.sh.

GPIO buttons do nothing

  1. GPIO needs the gpiozero Python package. Without it the console prints GPIO unavailable: gpiozero not installed or import failed.
  2. Settings › Input › Remap Input. Press any GPIO button first ("GPIO detected"). Then press each button when asked: UP, DOWN, LEFT, RIGHT, A, B, X, Y, L, R, START, SELECT. A button not pressed within 15 seconds keeps its default.
  3. On Batocera, input_test.pygame (in the Batocera download) shows the GPIO, keyboard and controller events the device sends.

The game is slow on a Pi

  1. Settings › Display › Show FPS: ON, to see the frame rate.
  2. Settings › Display › Render Res: 1x. Each step up draws more pixels.
  3. Settings › Input › Test Graphics runs the graphics test again. On a Pi it picks the frame rate the device holds.

Version 1.0 holds 30 frames a second in every scene on a Pi Zero 2W.

Batocera

  • Batocera runs the game in its Pygame system, with its own Python and pygame. Some Batocera images lack them; the game cannot run there.
  • The game is always fullscreen on Batocera.
  • Folder and launcher: see the Installation Guide.

Display, sound and controls

The game opens at the wrong size

Windows and macOS start in a window. Linux, Raspberry Pi and Batocera start fullscreen.

  • Settings › Display › Window Size sets the window size. The game is scaled to fit. Dimmed in fullscreen.
  • Settings › Display › Render Res sets the internal resolution, 1x to 4x.
  • Fullscreen: start with --fullscreen or -f, or set OMNIPET_FULLSCREEN=1.

There is no sound

Settings › Audio › Volume: 0% to 100%, in steps of 10.

The buttons do the wrong thing

Settings › Input › Remap Input. Press any button on the device to use (keyboard, controller or GPIO), then each button when asked. The default keyboard keys:
