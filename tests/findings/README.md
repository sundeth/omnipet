# Findings

One file per test area (`training.md`, `ic.md`, `battle.md`, `online.md`, `android.md`, `platform.md` ...): bugs and gaps the tests found in the game, each with the test that shows it (usually marked `@unittest.expectedFailure` until fixed), the file and line in `src/`, and the checklist id. Fixed entries are struck through with the date, not deleted, until the next release pass.
